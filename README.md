# Legal AI Architecture Survey — Corpus

This repository contains the full corpus (n = 98) reviewed in:

**"A Novel Architecture-Centric Taxonomy of Legal Artificial Intelligence: Fine-Tuned LLMs, Retrieval-Augmented Generation, Knowledge-Graph Reasoning, and Multi-Agent Frameworks — A Systematic Survey and Benchmark Gap Analysis"**
Osman Osama, Egyptian Chinese University

## Contents

- `Legal_AI_Survey_Corpus_Appendix_A.xlsx` / `.csv` — all 98 sources in the corpus, coded by primary architecture family (fine-tuned LLM, RAG, knowledge graph/GraphRAG, multi-agent, hybrid, benchmark, survey) and primary task, corresponding to Appendix A and Table 2 of the survey.

## Columns

| Column | Description |
|---|---|
| # | Source index (1–98) |
| Title (short) | Shortened paper/system title |
| Author(s) | First author(s), et al. where applicable |
| Year | Publication year (2020–2026) |
| Architecture | Primary architecture family per the taxonomy in Section 4 |
| Task | Primary legal task addressed |
